# Реестр проектов

Один проект — одна запись. Ведётся командой `bcf meta register`, правится руками.

Смысл реестра не в списке путей, а в **дате последнего аудита**: обвязка деградирует
молча. Хук, который перестал срабатывать после обновления CLI, не сообщает об этом —
он просто пропускает то, что раньше блокировал, и проект ещё месяцами выглядит
защищённым.

---

## Формат записи

```
## <имя проекта>
- **Путь:** `D:\path\to\project`
- **Тип:** web-app | cli | service | lib | data | desktop | other
- **Статус:** active | maintenance | archived
- **CLAUDE.md:** есть (N строк) / нет
- **Хуки:** сколько и какие ключевые / нет
- **Скилы:** число
- **Судьи:** перечислить / нет
- **Память:** подключена / нет
- **Последний аудит:** YYYY-MM-DD
- **Заметки:** …

### История аудитов
| Дата | Что нашли | Что сделали |
|------|-----------|-------------|
```
