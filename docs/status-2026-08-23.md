## Проблемы

1. **Двенадцать дней работы без коммита.** Один сбой диска или случайный checkout — и правки исчезнут. Закоммитить в первую очередь.
2. **harness/events.jsonl закоммичен в git и пачкается при каждом прогоне.** По собственному дизайну фабрики журнал живёт в .bcf/ целевого проекта; этот файл — остаток старого расклада, он в статусе modified прямо сейчас и будет грязнить дерево после каждого запуска. Убрать из индекса, добавить в .gitignore.
3. **Три мёртвых рабочих дерева и ветки от агентов:** claude/adoring-edison-eb074d, claude/mystifying-elion-ca2ac3, claude/quizzical-moore-1469f3. Все стоят на начальном коммите, работы в них нет. `git worktree remove` и удалить ветки.
4. **В журнале прошлого прогона видна дыра, которую как раз закрыли:** задачи TASK-53…55 получили PASS с пустым диффом (отпечаток e69de29… — это хеш пустого блоба git). Исправление есть в незакоммиченных правках, что ещё один довод их закоммитить.
5. **Запись testproj3 в meta/registry.md указывает на временный каталог** в AppData\Temp от 31 июля — путь почти наверняка мёртвый, запись можно почистить или пометить archived.

## Что делать, по порядку

1. Закоммитить текущее дерево (тесты уже зелёные).
2. Вынести harness/events.jsonl из git.
3. Снести мёртвые worktrees и ветки.
4. Почистить реестр проектов.

Пункты 2–4 механические, займут несколько минут.
