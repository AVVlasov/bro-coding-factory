# Дорожная карта фабрики

Задачи ниже меняют движок и шаблоны фабрики. Каждая закрывается живым прогоном и своей
сюитой в `tests/all.ps1`, а не описанием. Оценки в часах работы человека с агентом.

## Закрыто

| Задача | Что изменилось | Слито |
|---|---|---|
| M-01 Фабрика водит Java | `detect` узнаёт Maven, пресет `require-tests` считает пройденные тесты по XML surefire, хуки и шаблоны под Java и Liquibase, backpressure читается из `config/harness.json` | 2026-09-04, сюиты maven-runner 24 и java-hooks 61 |
| M-02 Исполнитель как поле задачи | строки `Исполнитель:` и `Блокер:` в шапке задачи; задачи с исполнителем-человеком `run night` и `run queue` в очередь не берут; `bcf task new --for` | 2026-09-04, сюита executor-field 21 |
| M-04 Честность вердикта | гейт на слитом дереве с четырьмя исходами вместо fail-open, защита `config/` и `tasks/` от правок агента, без модальных окон, `doctor` проверяет состояние git | 2026-09-04, сюита verdict-honesty 58 |
| M-05 Сервер и CI | память проекта одна на команду (поле `project`, миграция, отзыв сначала по своему), реестр агентских слотов один на установку фабрики, порт памяти в накладке машины, `bcf init`/`install` подставляют bash полным путём (`git --exec-path` → известные каталоги → PATH, без WSL) и отказывают без него вместо голого `"bash"`, `secret-scan.sh` блокирует коммит с похожим на ключ доступа, `doctor`/README объявляют Windows требованием, CI на `windows-latest` гоняет `tests/all.ps1` на каждый push и pull request | 2026-09-05, сюиты memory-team 68 и install-secrets 37 |

## В работе, по порядку

| Задача | Что должно измениться | Оценка |
|---|---|---|
| M-03 Фабрика в команде | вердикты и заявки на задачи живут в git и видны всем участникам; `fetch` перед прогоном и `push` после зелёного; откат без `reset --hard`; ветка волны и pull request вместо коммита в main; номер задачи выдаётся по `origin` | 45 ч |
| M-06 Приёмка лидерами | профили критиков лежат в проекте, у задачи ссылка на требование заказчика, запись о приёмке лидером направления, выгрузка отчёта для заказчика, трейлеры коммитов | 30 ч |

Заводит и принимает задачи владелец фабрики. Задачи продукта в эту карту не входят: они
лежат в `tasks/` своего репозитория.
